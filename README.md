# Olympiad Portal

A private math olympiad platform for creating, reviewing, and rating competition problems.

## Technologies

* Next.js 16 + React 19 + TypeScript
* PostgreSQL + Prisma
* Tailwind CSS + shadcn/ui
* React Hook Form + Zod
* KaTeX + Argon2id
